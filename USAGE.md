# TrailPoint usage

Build and run the app from this folder:

```sh
swift run
```

TrailPoint lives in the menu bar as a cursor icon. Select **Stop Trail** to pause it or **Quit TrailPoint** to exit.

If the trail works only while TrailPoint is active, enable **Input Monitoring** for the terminal (or for a packaged TrailPoint app) in **System Settings → Privacy & Security**, then restart it.
